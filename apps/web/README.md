# NEXUS.ai Web

Next.js frontend for the NEXUS.ai modular monolith.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Recharts (charts added in later phases)

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Environment

Copy the root `.env.example` to `.env` and set:

```
NEXT_PUBLIC_API_URL=http://localhost:8000
```
